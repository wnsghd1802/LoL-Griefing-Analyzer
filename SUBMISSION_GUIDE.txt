[짧은 확인 방법 4줄]
1. 공개 사이트에 접속해 영상 선택 화면을 확인합니다.
2. '예시 결과 보기'를 누르면 가상의 채팅 로그와 의심 표현 후보가 표시됩니다(실제 경기 결과가 아님).
3. 실제 LoL 영상 파일을 선택하면 자동 OCR 분석이 시작되고, 인식 글자와 의심 시점이 한 화면에 표시됩니다. 실제 영상 인식률은 추가 검증이 필요합니다.
4. 라이엇 ID로 전적 검색을 열고 전적표 스크린샷을 선택해 KDA·CS 후보를 확인한 뒤 결과를 TXT로 저장할 수 있습니다. 이미지 OCR 결과는 원본과 대조해야 합니다.

[AI와 나의 판단 3줄]
AI 활용: 화면 디자인과 브라우저 OCR 연동, 채팅 문구 분류, 이미지 점수 추출 로직, 테스트 코드의 생성·수정에 AI를 사용했습니다.
내 판단: 메뉴가 많고 사용자가 수동으로 자료를 입력해야 하는 구조를 개선하여 '영상 선택 한 번 → 자동 분석 → 결과 도출'을 중심 사용 흐름으로 결정했습니다.
최종 판단: 단편적인 채팅, KDA, CS 수치만으로 비협조 행위를 확정하지 않으며, 실제 LoL 영상에서 검증하지 못한 정확도는 완료 성능이라고 표기하지 않겠습니다.

[BR-B 5/5 동료 사용성 피드백]
익명 한 줄 감상(제공받은 원문): “페이지의 의도는 좋으나 페이지가 너무 번잡스럽다 좀 더 한 눈에 보였으면 좋겠다.”
문제: 너무 많은 메뉴/수동 입력 탓에 첫 사용자에게 핵심 기능이 잘 보이지 않음.
반영: 단일 페이지 자동 분석 흐름, 채팅 시간순 로그, 결과 요약 및 저장으로 재구성. 세부 기술 입력은 기본 화면에서 제거.
안내: 페이지 하단에 원문과 개선 내용이 노출됩니다. 동료의 실제 사용 과정 및 추가 증빙은 별도 보관이 필요합니다.

[연계 논문]
「팀 기반 온라인 게임에서 비협조적 행동의 발생 요인과 제재 판단의 한계에 관한 연구」
장면 발견 → 분류 → 맥락 점검 → 반례 확인 → 최종 검토.
웹앱에서 고의성·운영사 제재 여부는 최종 판정하지 않습니다.

[미검증 상태]
- 실제 LoL 녹화에서 OCR 탐지 성능 수치 미측정 (오탐·누락 가능)
- 실제 전적 사이트 캡처별 이미지 OCR 추출 정확도 미측정
- BR-A 포트폴리오의 앱 링크 존재 여부 미검증
- 시크릿 창 직접 방문 및 외부 사용자의 4가지 테스트 이력은 검증 필요

[기술 안내]
Riot API 키를 클라이언트에 넣지 않았습니다. 전적 검색은 OP.GG 페이지 새 탭 연결이며 외부 데이터를 직접 수집하는 API 연동이 아닙니다.
